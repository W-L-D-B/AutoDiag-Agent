## 场景验证

七个固定场景均通过实际独立进程和内核 SocketCAN 运行：

- 正常：三个节点 online/fresh。
- BMS 状态丢失：心跳继续，但数据 stale。
- HVAC CRC 损坏：拒绝计数增加，坏数据不续期。
- Body 序号冻结：重复帧被拒绝，最终 stale。
- BMS 过温：125°C 作为协议有效数据进入快照。
- LIN 校验损坏：HVAC 保留 last-good 温度并清除有效位。
- Body 退出：预期退出码 42，随后节点 offline。

附加集成用例覆盖序号回绕、DBC 独立解码、相同 seed 的匹配数据、非空输出保护、物理接口拒绝、同接口并发锁、异常子进程与 SIGINT 清理、输出软硬链接保护，以及持续报文下的有界停止。

## 质检发现并修复的问题

| 问题 | 修复与回归 |
|---|---|
| JSON 可选标量被写成数组 | 使用明确的标量／null 构造，增加 JSON 类型断言；独立回放核验通过 |
| 日志与快照路径相同或别名时可能丢证据 | 创建前检查路径，日志独占且不跟随软链接，快照使用唯一临时文件与原子替换 |
| 清理阶段首次中断可能打断进程回收 | 整个最终清理和 manifest 落盘期间延迟 SIGINT/SIGTERM，增加确定性信号注入测试 |
| 回放只检查 DBC ID，可能接受缩放漂移 | 校验完整 v1 语义契约，覆盖 offset、scale、布局、符号、字段和重复 ID 篡改 |
| 心跳使用计划时间而非实际 uptime | 改为发送时读取单调时钟 |
| 连续收帧可能饿死停止检查 | 每帧检查停止标志与截止时间；原回归在 1.5 秒退出限制内失败，修复后通过 |
| Windows 挂载目录不能保留 Linux 私有权限 | 在专用 WSL 发行版启用 DrvFs metadata，并实测 D 盘新建证据目录的权限 |
| 激活脚本清除了调用者变量 | 使用独立变量名，完整质量脚本执行通过 |
