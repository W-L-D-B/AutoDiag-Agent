## 五项失败与语义抽查

`task-002/004/005` 为 invalid_model_response：提供商响应未满足适配器约束；原始 HTTP 响应未保留，不能进一步猜测具体原因。`task-007` 最终输出不符合严格 JSON；`task-033` 不符合报告结构约束。它们全部计为失败，未回退规则答案来抬高模型成绩。

55 份完成报告重新通过结构、证据 ID 和证据类型检查。这仅说明引用存在于本次任务，不证明所有自然语言描述正确。

对每个场景族第一份完成报告进行定向人工抽查，共 12 份，发现 `task-041` 有明确的错误数值解释：模型根因正确定位 scaling_mismatch，也引用了正确的 400.3 V 工具结果，但解释字节时写成 `A30F=41743`、按 `0.01 V/LSB` 得到 400.3 V。正确解析应为小端 `A3 0F = 4003`，乘 `0.1 V` 得到 400.3 V。C++ 已正确解析，错误发生在模型的文字说明。

因此不报告“零幻觉”，也不把 55/60 称作全文事实准确率。此抽查是 12 份定向样本，不能外推全量幻觉率。模型结论与解释需要结合结构化原始值阅读；未来可扩展字段路径引用和逐项数值校验。

规则基线面向已知场景与固定问句，成绩高于模型，说明这组确定场景可用显式规则稳定处理。模型承担自然语言入口、调查工具选择和证据组织；当前实验没有证明模型在未知车型、自由问句或真实车辆上优于规则。
