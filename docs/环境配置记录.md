## 日常进入项目

```powershell
cd D:\Code\mi\AutoDiag_Agent
.\scripts\dev.ps1
```

进入 Linux 后：

```bash
source scripts/activate.sh
sudo /usr/local/sbin/autodiag-vcan up
python tools/check_environment.py
```

`autodiag` 只对固定的虚拟 CAN 启停命令拥有无密码 sudo 权限。常规系统管理可以在 Windows 用 `wsl -d AutoDiagUbuntu -u root` 进入；如需要常规 sudo，在 root 会话运行 `passwd autodiag`，自行设置密码。

项目目录迁移后，已有 CMake 缓存可以在项目根目录执行 `cmake --fresh --preset linux-debug` 重建。`.env`、临时简历预览、运行产物和个人调研稿均仅保留本地。
